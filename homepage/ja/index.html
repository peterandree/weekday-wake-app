もっと賢く目覚める、無理はしない

Weekday Wake は、勤務スケジュールに合わせて自動調整する賢いアラームアプリです。 週末と祝日はスキップされるので、必要なときだけ目覚められます。

仕様

言語

English, Deutsch, Español (LatAm), Français, Português (Brasil), 中文 （简体）, 日本語, など。

対応 Android

Android 12（Snow Cone）以降。

権限

  • USE_EXACT_ALARM ‐ 設定した分にアラームを鳴らす
  • POST_NOTIFICATIONS ‐ アラームと事前予告の通知を表示
  • FOREGROUND_SERVICE ‐ 信頼性ガードを生かし続ける（任意の層）
  • RECEIVE_BOOT_COMPLETED ‐ 再起動後にアラームを再設定
  • WAKE_LOCK, VIBRATE ‐ アラーム時刻に起こして振動させる
  • INTERNET, ACCESS_NETWORK_STATE ‐ 祝日カレンダーのダウンロード専用

位置情報の権限は一切要求しません。

検証可能なプライバシー

完全な証拠 ‐ 正確な権限リスト、祝日のための唯一の外向き通信と その中身、ストアのデータ安全への記載 — はプライバシーページ に文書化されています。アラーム、スケジュール、設定が端末から出ることはありません。

機能

📅

スマートなスケジューリング

選んだ地域の週末と祝日には、アラームを自動で鳴らしません。

🌍

地域に対応

国と地方区分の公式な祝日・勤務日パターンに合わせて動作します。地域を選び、独自の祝日を追加し、個別のアラームを強制的に鳴らせます — すべて位置情報の許可なしで。

⚙️

勤務日をカスタマイズ

自分の勤務スケジュールを定義できます。シフト勤務や変則週にも最適です。

🏖️

祝日もカスタマイズ

個人の祝日、休暇、ゆっくり寝ていたい日を追加できます。

🔔

複数アラーム

曜日ごとに別のアラームを、ラベルとサウンド付きで設定できます。

🎨

美しい UI

Material Design に沿った、洗練されたモダンなインターフェイス。

よくある質問

Weekday Wake は iOS にもありますか？

現在、Weekday Wake は Android 専用です。iOS 版は今後も予定していません。

オフラインでも使えますか？

はい！地域と勤務スケジュールを選べば、完全オフラインで動作します。祝日データはローカルにキャッシュされます。

アプリは祝日をどこで知るのですか？

Weekday Wake は各国の公開されている祝日データを使います。地域を選ぶと、それに対応する祝日カレンダーをダウンロードします。

端末間でアラームを同期できますか？

できません。Weekday Wake にはアカウントもクラウド同期もなく、アラームがどこかに送信されることもありません。設定は端末ごとです。

データのプライバシーは守られますか？

アラームのデータ、選んだ地域、カスタム設定はすべて端末内に保存されます。検証可能な証拠は プライバシーページ をご覧ください。

バグ報告や機能要望はどうすれば？

GitHub リポジトリに issue を立ててください。端末モデル、Android のバージョン、再現手順など、できる限り詳しくお願いします。
